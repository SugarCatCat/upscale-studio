图片超分

GAN 超分模型，快。可同时拖入多张，逐张处理。
点击选择 或把图片拖到这里 支持 png / jpg / webp / bmp / tiff，可多选
或填本地路径（文件夹 / 单文件，直接读本地、不占上传）
选择文件或填入路径后显示耗时预估
倍率是「最终尺寸倍数」。选 4x 模型 + 目标 2 倍时，会自动按 0.5 缩放，成本仍是 4x 的算力。

视频补帧 + 超分

RIFE 补帧 → 逐帧超分 → 自动分段拼接，保留原音轨。
点击选择 或把视频拖到这里 支持 mp4 / mov / mkv / webm，可多选
或填本地路径（文件夹 / 单文件，直接读本地、不占上传）
选择文件或填入路径后显示耗时预估
长视频会按「内存预算 + MPS 单张量上限」自动切段再拼接，不用手动切； 帧率也不用管，按「源帧率 × 倍率」自动算。
参考耗时（720p 源）：轻量模型 0.18 秒/帧，x2plus 1.5 秒/帧，x4plus 5.9 秒/帧。
追求速度选 realesr-animevideov3（快 30 倍，动画/CG 几乎看不出差别）；追求极致细节选 x4plus。
